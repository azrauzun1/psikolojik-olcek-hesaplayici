
# Psikolojik Ölçek Puanı Hesaplayıcısı

## Proje Hakkında
Bu proje, GEP1316 Kodlama Okuryazarlığı dersi kapsamında Python kullanılarak geliştirilmiştir.

Program, üç örnek psikolojik ölçek maddesine verilen puanları alarak toplam ve ortalama puanı hesaplar.

Bu uygulama eğitim amaçlıdır. Geçerliliği ve güvenirliği kanıtlanmış bir psikolojik ölçek değildir; tanı veya klinik değerlendirme amacıyla kullanılamaz.

## Programın Özellikleri
- Kullanıcıdan ad veya takma ad alır.
- Üç madde için 1–5 arasında puan ister.
- Puanların belirtilen aralıkta olup olmadığını kontrol eder.
- Geçerli puanların toplamını hesaplar.
- Ortalama puanı iki ondalık basamakla gösterir.
- Aralık dışındaki puanlar için hata mesajı verir.

## Kullanılan Teknoloji
Python 3

## Çalıştırma
1. `psikolojik_olcek_hesaplayici.py` dosyasını açın.
2. Python 3 ortamında çalıştırın.
3. Adınızı veya takma adınızı girin.
4. Üç madde için puanları yazın.
5. Toplam ve ortalama puanı görüntüleyin.

## Örnek Hesaplama
Girilen puanlar: 3, 4, 5

Toplam puan: 12

Ortalama puan: 4.00
